#include <stdio.h>
#include <string.h>
int main() {
    char S[1111];
    int n;
    S[1]=1;
    int len = strlen(S);
    for(int i=0;i<len;i++){
        S[i]=S[i-1]=1;
    }
    scanf("%d",&n);
    printf("%s",S[n]);
    return 0;
}
上述为错误代码


关注几个问题
第一：逻辑是否正确，能否生成有效字符串
第二：会不会出现数组越界的问题
第三：对于字符，字符串的输出方式是否正确


针对第一种，是将这个字符串单独拆成了数组还是统一输出了

针对第二种S[1] = 1;：这里有两个问题。第一，字符应该用单引号 '1'（ASCII 码 49），而不是整数 1（控制字符）。第二，把字符串的第 2 个位置设为 1，第 1 个位置却是垃圾值。

字符串和数组是一样的，下标都是从0开始
