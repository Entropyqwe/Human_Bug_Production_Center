在 C 语言中，遍历字符串是一项极其基础且核心的操作。因为 C 语言没有专门的字符串类型，字符串本质上是以空字符（`\0`）结尾的字符数组。

针对字符串遍历，主要有以下三种核心方法，它们各有特点：

### 1. 基于数组下标的 `for` 循环遍历
这是最常见且最符合直觉的遍历方式。程序通过一个递增的索引变量 `i`，依次访问数组中的每一个字符。

*   **实现方式**：通常结合 `strlen()` 函数获取字符串长度作为循环的终止条件，或者直接在条件中判断当前字符是否为 `\0`。
*   **代码示例**：
    ```c
    char *str = "This is an example.";
    size_t length = strlen(str);
    for (size_t i = 0; i < length; i++) {
        printf("%c", str[i]); // 通过 str[i] 访问字符
    }
    ```
*   **⚠️ 性能避坑**：强烈建议将 `strlen(str)` 放在 `for` 循环的外部（如示例所示）。如果写在循环条件里（如 `i < strlen(str)`），`strlen` 会在每次迭代时被调用一次，导致极大的性能浪费。

### 2. 基于数组下标的 `while` 循环遍历
这种方式不需要提前计算字符串的长度，而是利用 C 语言字符串以 `\0` 结尾的特性，遇到结束符即停止。

*   **实现方式**：初始化索引 `i = 0`，在 `while` 循环中判断 `str[i] != '\0'`。
*   **代码示例**：
    ```c
    char *str = "This is an example.";
    size_t i = 0;
    while (str[i] != '\0') {
        printf("%c", str[i]);
        i++;
    }
    ```
*   **💡 进阶写法**：由于在 C 语言中，任何非零值都被评估为 `true`，因此循环条件可以极致简化为 `while (str[i])`，代码更加干练。

### 3. 基于指针的遍历
指针是 C 语言的灵魂。通过移动指针的地址来访问字符，这种方式比数组下标更加灵活，也是底层字符串函数（如 `strlen`、`strcpy`）的标准实现方式。

*   **实现方式**：定义一个临时指针指向字符串首地址，通过解引用 `*p` 获取字符，通过 `p++` 移动指针。
*   **代码示例**：
    ```c
    char *str = "This is an example.";
    char *p = str; // 复制指针，避免修改原始指针
    while (*p != '\0') {
        printf("%c", *p);
        p++; // 指针向后移动一个字符位置
    }
    ```
*   **💡 进阶写法**：可以将解引用和指针自增合并，写成 `while (*p)` 配合 `printf("%c", *p++)`，进一步精简代码。

---

**总结建议**：
*   如果你需要知道当前字符的**确切位置（索引）**，推荐使用 **`for` 循环 + 数组下标**。
*   如果你只需要**挨个处理字符**，不关心具体位置，推荐使用 **`while` 循环 + 指针**，这种方式在 C 语言底层开发中最为高效和常见。
