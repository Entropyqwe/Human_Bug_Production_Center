为什么主函数要写 int main(void)？

核心原因
向操作系统汇报结果：int 表示程序结束时，会向操作系统返回一个整型状态码（Exit Status）。通常返回 0 代表“成功退出”，返回非 0（如 1, 2）代表“遇到错误”。这能让外部脚本（如 Shell）根据返回值决定下一步操作。
严谨的参数声明：括号里的 (void) 明确告诉编译器，该主函数绝对不接受任何外部传入的参数。
跨平台兼容性：这是 C99 及后续标准中唯一合法的无参主函数写法，保证了代码在任何编译器下都能顺利运行。

常见的错误写法：void main()
非标准写法：C++ 之父 Bjarne Stroustrup 曾明确表示，void main() 从来就不存在于 C 或 C++ 标准中。
无法交差：它剥夺了程序向操作系统返回状态码的能力，导致系统不知道程序是正常结束还是中途崩溃。

int main(void) 与 int main() 的区别

int main(void)：明确表示“无参数”，是现代 C 语言的标准写法（强烈推荐）。
int main()：在 C 语言中表示“参数未指定”（即不限制参数个数和类型），属于历史遗留的“坑”，编译器无法检查非法参数传入。
注意：在 C++ 中，int main() 和 int main(void) 是完全等价的，但在 C 语言中请始终使用 int main(void)。

什么是 void f(void)？它不能输出吗？

核心误区澄清
void f(void) 完全可以在内部调用 printf 输出内容！

void 的双重含义
最前面的 void（返回值类型）：表示函数执行完毕后，不会通过 return 语句向调用者交回任何计算结果。但这不等于不能在屏幕上打印信息（打印是向外部世界广播，返回是内部交易）。
括号里的 (void)（参数列表）：表示函数在启动时，不需要接收任何外部传入的参数。

字符串比较核心函数：strcmp

为什么不能用 ==？
在 C 语言中，str1 == str2 比较的是两个字符串在内存中的首地址，而不是内容。判断字符串相等，唯一正确的姿势是 strcmp(str1, str2) == 0。

strcmp 返回值规则
返回值   含义   底层原理
= 0   str1 与 str2 完全相同   所有字符及长度均一致，直到 0 都相等。

 0   str1 大于 str2   在第一个不相同的位置，str1 的 ASCII 码大于 str2。

int main(void) {
    // 1. 完全相同：返回 0
    printf("Apple vs Apple: %dn", strcmp("Apple", "Apple")); 

    // 2. 字典序小于：返回 负数
    printf("Apple vs Banana: %dn", strcmp("Apple", "Banana")); 

    // 3. 字典序大于：返回 正数
    printf("Banana vs Apple: %dn", strcmp("Banana", "Apple")); 

    // 4. 区分大小写：返回 负数 ('a' > 'A')
    printf("Apple vs apple: %dn", strcmp("Apple", "apple")); 

    return 0;
}
