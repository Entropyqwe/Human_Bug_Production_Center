这段代码是 OpenCV 形态学运算的"全家桶"示例。我把里面出现的**所有专业名词**分成四个层次，从"图像长什么样"到"怎么雕形状"，逐一拆解清楚。 

4.相关名词

4.1，灰度图

把彩色图"去色"后的图。每个像素只剩**一个数值**（0~255），0 代表纯黑，255 代表纯白，中间是各种深浅的灰。

彩色照片是"三棱镜"（红绿蓝三种光混在一起），灰度图就是把棱镜拿掉，只看"光的强弱"。

`cv.imread('02.png', cv.IMREAD_GRAYSCALE)` 中的 `IMREAD_GRAYSCALE` 就是"读进来时直接当成灰度图"。

4.2，二值图

比灰度图更"极端"。每个像素**只有两个取值**：要么 0（黑），要么 255（白），没有中间灰色。

灰度图是"亮度旋钮"（可拧到任意档），二值图是"开关"（只有开/关两种状态）。

形态学只关心"哪里是物体、哪里是背景"这种**形状**问题，把图压成黑白，能让"物体边界"最干净利落。

灰度图保持了亮度信息，可以说是不同程度的黑

而二值图像只会存在黑（255）或者灰度图（0）

4.3，前后背景

前景：目标物体，在二值图里通常用白色（255)表示。

背景：物体之外的部分，通常是黑色（0）。

注意：形态学里默认"白色=物体"。所以后面说"腐蚀让白变少"，其实就是"把物体削小一圈"。

4.4像素值

就是每个点的那个数字（0~255）。代码里 `像素值 > 127 设为 255` 就是在拿这个数字做比较。

4.5二值化 / 阈值化（Binary Thresholding）

灰度值超过线的判为白，没过的判为黑。这是把灰度图变二值图的那道工序。

4.6阈值

`cv.threshold(img, 127, 255, ...)` 里的 `127` 是线，`255` 是过线后被赋的白值。

127 差不多是 0~255 的正中间，所以是"一刀切"的常用默认值。4.7阈值类型

大于阈值→给最大值(255)，否则→0。还有别的类型如 `THRESH_BINARY_INV` 反相、`THRESH_OTSU` 自动找线等。

`_, binary = ...` 里那个开头的 `_`，是因为函数会返回两个值（第一个是它自动算出的最优阈值，这里我们自己定死了 127，所以用 `_` 把它丢掉不要）。

结构元素

4.8卷积核（Kernel）

形态学运算的核心工具，一个**小矩阵**（通常是 3×3、5×5 这种奇数尺寸）。算法拿着它在整张图上滑动，靠它的形状去判断怎么改像素。

4.9`cv.getStructuringElement`（创建结构元素的函数）专门用来"造印章"的函数。两个关键参数：**形状** + **大小**。

4.10`MORPH_RECT` / `MORPH_ELLIPSE` / `MORPH_CROSS`（核的三种形状）

* `MORPH_RECT` 矩形：实心方块印章，最常用、最"暴力"。

* `MORPH_ELLIPSE` 椭圆/圆形：圆润印章，处理结果边缘更圆滑，适合处理圆形物体。

* `MORPH_CROSS` 十字：只有横竖两条线，处理结果更"锐利"，常用于只需水平/垂直方向作用的场景。

* **比喻**：同一个动作，换"方印章 / 圆印章 / 十字印章"，雕出来的轮廓手感完全不同。

* 运算类名

> 这里有个统一的记忆钥匙：**腐蚀=取最小值=白往黑缩；膨胀=取最大值=黑往白胀。** 后面五种全是这两种的基本功或组合拳。



4.11腐蚀（Erosion）

* **原理**：印章盖下去，盖住的区域里只要有一个是黑，中心就判黑（取最小值）。
* **效果**：白色物体"瘦身"，向外缩一圈。
* **用途**：吃掉白色噪点、把粘连的物体切断。
* **比喻**：拿铲子沿物体边缘往里削一层皮。

4.12. 膨胀（Dilation）

* **原理**：印章盖下去，盖住的区域里只要有一个是白，中心就判白（取最大值）。
* **效果**：白色物体"长胖"，向外扩一圈。
* **用途**：填黑色小孔、把断裂的线条接起来。
* **比喻**：拿粗笔沿物体边缘往外描一圈边。

4.13. `iterations`（迭代次数）

* 指这个动作**重复执行几遍**。`iterations=1` 是削/描一遍；设成 3 就是连做三次，效果（变瘦/变胖的程度）会叠加放大。

4.14. `cv.erode` / `cv.dilate`

* 分别就是"执行腐蚀""执行膨胀"的函数。

4.15. 开运算（Opening）= 先腐蚀后膨胀

* **比喻**：先拿铲子把边缘毛刺、外围小白点削掉（腐蚀），再拿笔把主体大小描回来（膨胀）。
* **效果**：主体大小基本不变，但**外围的细小白色噪点被清干净**。
* **记法**："**开**"像开门——把不干净的小白点"开"出去。
* 4.16闭运算（Closing）= 先膨胀后腐蚀

* **比喻**：先用笔把物体内部的黑孔、裂缝填满（膨胀），再用铲子把多描出来的边削掉（腐蚀）。
* **效果**：主体大小基本不变，但**内部的黑色小孔被填平**。
* **记法**："**闭**"像关门——把里面的洞"闭"上。
* 开/闭是一对镜像组合：先腐后膨 vs 先膨后腐。

#### 5.4 Canny 边缘检测

5.4.1

流程：高斯滤波——梯度计算——非极大值抑制NMS——双阈值——滞后链接

梯度计算用soble算子计算

 语法: cv.Canny( image, threshold1, threshold2, apertureSize )

 threshold1 - 低阈值（弱边缘

threshold2 - 高阈值（强边缘

apertureSize - Sobel 核大小（默认3）

5.4.2如何判断具体填入多少

Canny 的高低阈值**没有一个对所有图片都通用的固定值**，通常要按“**先定高阈值，再按 1:2 ~ 1:3 算低阈值**”来调。

常用起点Canny(image,50,150)

手动调参怎么判断？

| 现象         | 说明          | 怎么改             |
| ---------- | ----------- | --------------- |
| 边缘太多、碎点很多  | 阈值太低        | 把高阈值、低阈值都调高     |
| 边缘断断续续     | 高阈值太高       | 把高阈值调低          |
| 只有很粗的主轮廓   | 阈值太高        | 同时降低高低阈值        |
| 噪声很多但主轮廓清楚 | 低阈值太低       | 只提高低阈值，高阈值不动    |
| 边缘太细、断得厉害  | 低阈值太低或高阈值太高 | 缩小两者差距，比如改成 1:2 |

高阈值决定：**哪些边缘一定保留**。低阈值决定：**哪些弱边缘可以跟着强边缘一起保留**。

5.4.3自动检测

自动计算阈值

def auto_canny(image, sigma=0.33):

 gray = cv.cvtColor(image, cv.COLOR_BGR2GRAY) 

blurred = cv.GaussianBlur(gray, (5, 5), 0) 

median = np.median(blurred)

 low = int(max(0, (1.0 - sigma) * median)) 

high = int(min(255, (1.0 + sigma) * median)) 

return cv.Canny(blurred, low, high)

实际上是定义了一个名叫auto-canny的自动计算函数
