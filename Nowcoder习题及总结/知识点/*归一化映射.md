归一化映射。
在计算机里，字母和数字本质上都是数字（ASCII 码），但直接对字母做数学运算（比如取余数 `%`）会很麻烦，因为 `'a'` 是 97，`'z'` 是 122，它们不是从 0 开始的。
为了方便计算，我们需要把它们“翻译”成 0 到 25 的数字，算完后再“翻译”回去。
 1. 字母变数字（归一化）
公式：`x = char - 'a'`
原理 在 ASCII 码表中，小写字母是连续排列的。`'a'` 的数值最小。
操作：当前字母减去起始字母 `'a'`。
效果：
 `'a' - 'a'` = 97 - 97 = 0
 `'b' - 'a'` = 98 - 97 = 1
...
`'z' - 'a'` = 122 - 97 = 25
已周期为标准
为什么要这样做？ 
这样我们就得到了一个 0~25 的索引，正好对应 26 个字母的下标，非常适合用来做取模运算（`% 26`）。

 2. 中间的计算（移位与循环）
假设我们要把字母向后移动 `n` 位（加密）：
`new_x = (x + n) % 26`
`+ n`：表示向后移动。如果是解密就是 `- n`。
`% 26`：这是核心。因为字母表只有 26 个，超过 25 就要回到 0。取模运算能自动处理这种“轮回”。
    - 比如 `'z'` (25) 向后移 1 位：`(25 + 1) % 26` = `26 % 26` = 0(即 `'a'`)。完美闭环！
 3. 数字变字母（还原）
公式： `char = x + 'a'`
原理： 计算结束后，我们手里拿着的是 0~25 的数字。
操作： 把起始字母 `'a'` 加回去。
效果：
0 + `'a'` = 'a'
1 + `'a'` = 'b'
25 + `'a'` ='z'
假设我们要加密字母 `'c'`，偏移量 `n = 2`：

| 步骤 | 代码逻辑 | 实际数值运算 | 结果 |
| :--- | :--- | :--- | :--- |
| **1. 变数字** | `'c' - 'a'` | 99 - 97 | **2** |
| **2. 移位** | `2 + 2` | 4 | **4** |
| **3. 取模** | `4 % 26` | 4 (没超过26，不变) | **4** |
| **4. 变字母** | `4 + 'a'` | 4 + 97 | **'e'** |

假设我们要加密字母 `'y'`，偏移量 `n = 2`（这就涉及循环了）：

| 步骤 | 代码逻辑 | 实际数值运算 | 结果 |
| :--- | :--- | :--- | :--- |
| **1. 变数字** | `'y' - 'a'` | 121 - 97 | **24** |
| **2. 移位** | `24 + 2` | 26 | **26** |
| **3. 取模** | `26 % 26` | **0** (关键点！回到起点) | **0** |
| **4. 变字母** | `0 + 'a'` | 0 + 97 | **'a'** |

这就是为什么代码里总是写着 `(password[i] - 'a' ... ) + 'a'`
