这道题（noob54 斗兽棋）考察的是 **字符串输入** 和 **逻辑判断**。
### 核心思路
1. **定义变量**：定义两个字符数组，分别存牛牛和牛妹出的棋子。
2. **输入**：使用 `scanf("%s %s", ...)` 读取两个单词。
3. **判断胜负**：
   - 如果两个字符串一样，输出 `tie`。
   - 如果不一样，判断牛牛是否赢了（根据题目给出的 4 种克制关系）。
   - 否则就是牛妹赢了，输出 `lose`。

### C语言代码实现
```c
#include <stdio.h>
#include <string.h> // 必须包含这个头文件才能使用 strcmp

int main() {
    // 1. 定义两个字符数组，长度稍微给大一点（比如20），防止溢出
    char s1[20]; 
    char s2[20];

    // 2. 循环读取输入，直到没有数据为止 (EOF)
    // 题目虽然没明说多组输入，但通常这类OJ题用 while(scanf(...) != EOF) 是最稳妥的
    while (scanf("%s %s", s1, s2) != EOF) {
        
        // 3. 首先判断是否平局
        if (strcmp(s1, s2) == 0) {
            printf("tie\n");
        }
        // 4. 判断牛牛赢的情况 (s1 吃 s2)
        // strcmp(a, b) == 0 表示字符串 a 和 b 相等
        else if ((strcmp(s1, "elephant") == 0 && strcmp(s2, "tiger") == 0) ||
                 (strcmp(s1, "tiger") == 0 && strcmp(s2, "cat") == 0) ||
                 (strcmp(s1, "cat") == 0 && strcmp(s2, "mouse") == 0) ||
                 (strcmp(s1, "mouse") == 0 && strcmp(s2, "elephant") == 0)) {
            printf("win\n");
        }
        // 5. 剩下的情况就是牛妹赢
        else {
            printf("lose\n");
        }
    }

    return 0;
}
```

### 代码详解（新手必看）

#### 为什么不能用 `==` 比较字符串？
在 C 语言中，字符串是字符数组。如果你写 `if (s1 == s2)`，你比较的不是里面的文字内容，而是它们在内存里的**地址**。这几乎永远是错的。
- **正确做法**：必须使用 `<string.h>` 头文件里的 `strcmp(str1, str2)` 函数。
- **返回值**：
  - 返回 `0`：表示两个字符串内容**相等**。
  - 返回非 0：表示不相等。

#### 为什么要用 `while` 循环？
很多在线判题系统（OJ）的后台测试数据是多组的。比如它可能会一次性输入三行数据来测试你的程序。
- `while (scanf(...) != EOF)` 的意思是：“只要还能读到数据，就继续处理下一行”。这是最标准的 OJ 答题模板。

#### 逻辑简化技巧
题目里有 4 种赢的情况，4 种输的情况。我们只需要列出牛牛赢的 4 种情况（用 `||` 或者连接），剩下的自然就是输（或者平局）。这样代码写起来最少，不容易出错。
